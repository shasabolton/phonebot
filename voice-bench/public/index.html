Telnyx streaming

Audio goes to Telnyx live while you hold the button, and the reply is spoken as the chat writes it. Uses the Telnyx key and chat model.
Ultra voices cannot stream, so they are left out of this list. If a voice fails with "connection failed", that voice does not stream either. For a like-for-like test, set the plain Telnyx voice to the same voice.

Design a Telnyx voice from a description

Generate a sample, adjust the description and generate again until it sounds right (each try becomes a new version of the same design), then save it. Saving fills the Telnyx voice ID box and selects it as the streaming voice. Saved voices stay on your Telnyx account. Telnyx may charge for each sample.
